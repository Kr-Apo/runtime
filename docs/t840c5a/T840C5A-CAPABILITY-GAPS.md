# Capability gaps and product boundaries

|Layer|Demonstrated available|Limit blocking broader characters|
|---|---|---|
|Editor B6 author data|Bones, hierarchy, pivoted regions, Physics definitions/order, compatible bone clips, native Save/Reload|No new UI authoring qualification here; puppet seams/hat gap and simple key slopes remain author work. Existing weighted/FFD/skin/constraint author features are not certified by these fixtures|
|Native exporter|Exact v2 original-source export; PNG trim/atlas, multi-page, static setup draw order and default skin, bone channels and Physics|All chosen inputs are representable. No export failure or data loss found for these cases; this does not qualify arbitrary unused advanced channels|
|Core ReplayV1|120Hz canonical one-clip sampling,8 constraints with dependencies, clock/backlog, C3, B6 faults and pure previews|Selected contract excludes mixed IK/Transform/Path, events, layers/crossfade. Numeric skin calendars existing do not automatically authorize dynamic graphical skins|
|Pixi experimental|Both native puppets, static regions/default skin/Normal, exact and host-time, real WebGL2|Meshes/FFD, clipping, animated slots/order, dark tint/blends and visual skin changes explicitly refused|
|Phaser experimental|Same supported subset, deep animated transforms, public Game/Scene API and ownership|Same refusals; repeated driver VERSION validation and geometry/reprojection costs limit scaling. Phaser default filter must be made explicit for comparable screenshots|
|Legacy|Existing wider renderer feature set remains untouched|Stale specialized UV/filter expectations and unresolved dangling-attachment policy; not a reason to weaken Replay gates|

These characters increase complexity from Scout4 bones/3 regions/1 Physics to14/12/2 and26/21/8. They remain rigid region puppets, not representative of every artist's weighted anatomical rig. Continuous deformation across elbows, soft cheeks, clothing masks, alternate costumes and crossfades remain blocked by explicit Replay graphical exclusions, even where the Editor or Legacy reader can represent them. No channels or constraints were stripped to make loading pass. No new renderer, skin system, evaluator, schema field or export format was introduced.

The native fault variants deliberately become singular at tick9 and demonstrate safe refusal/rollback; they are diagnostic projects, not animation recommendations. Device/context loss, hardware portability, long-running production memory and artistic polish are not newly certified. RC2 and the original user projects remain unchanged.
