# C6A capability matrix

| Capability | Fixed C2 | Opt-in C6A | Proof / limit |
|---|---|---|---|
| Native v2 static regions / bone clips / Physics-only | Qualified unchanged | Qualified on two fixtures | Native Save/Reload/export; Rust numeric traces; real WebGL2 |
| One fixed default skin | Existing behavior | Explicit tick-zero calendar also required | C2 old tests/captures unchanged |
| Two/three skins, repeated changes | Refused | Qualified | Exact committed transitions; default/festival/night palettes and dimensions |
| Multi-page atlas | Existing | Qualified:2/4 pages | Actual submitted shader sources, UVs and pixels |
| Selected/default fallback / legitimate absence | Existing strict setup gate | Qualified native resolution | Festival-only badge, default thigh/scarf fallback |
| Skin Physics memberships | Existing numerical contract | Qualified with visible same-tick skin | Rust records/order/local/world positions |
| Backlog/partial pump/pause/resume | Existing | Qualified | 60 requested/8 completed; transition20; multiple pending transitions |
| Seek | Pure FK preview | Pure FK preview, labeled skin | Not simulated Physics history; replay required |
| Replay/reset/C3 host time | Existing | Qualified targeted + historical | Calendar retained; tokens/epochs guarded |
| Numeric transition fault | Existing B6 | Qualified at 20, retained19 | Actual native singular parent transform, no patched JSON |
| Borrowed/shared/owned pages | Existing | Qualified targeted | Strict identity/live/PMA checks; bounded slot caches |
| Opaque/transparent presentation | Existing pixel law | Qualified scenes on one GPU/browser | Original PNG texel oracle + Rust geometry; no new CPU raster oracle |
| Meshes (rigid or weighted), linked meshes, FFD | Refused | Refused | Legacy Pixi capabilities are not Replay capabilities |
| Clipping, sequences, slot/attachment/color animation, animated order | Refused | Refused | No projection/stripping of unsupported channels |
| Dark tint / Add/Multiply/Screen | Refused | Refused | Legacy renderer support does not qualify Replay |
| IK/Transform/Path or mixed constraints | Refused | Refused | Physics-only gate unchanged |
| Crossfade/layers/gameplay events | Refused | Refused | No inferred semantics |
| Phaser visual calendar | Not C6A | Not implemented | Phaser source/tests/default API untouched |
| Other browsers/mobile/WebGL1/WebGPU | Not certified | Not certified | Single Chrome/ANGLE/RTX3090 qualification |

Present and tested is distinct from supported by another renderer or merely representable in the format. No new alpha/public release claim follows this local checkpoint.
