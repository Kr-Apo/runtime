# Publication source provenance

This is a publication-only copy of the accepted Ankhimate source tree, prepared
for review in T-804.1. No public upload is performed by preparing this copy.

Personal Git author and committer fields are represented by the maintainer-
approved collective label Ankhimate Contributors, with an empty email field.
It denotes anonymization, not a claim that a different person authored old code.
Original legal copyright, license and third-party attribution text is retained.
Original repositories, commits and protected regression files remain untouched.

Home paths in documentation and fixture-source provenance are neutralized.
The provenance source labels qualification/... are portable logical labels, not
a promise that the private generation workspace is included. Destination hashes
and every native data/pixel oracle are unchanged. Three stored core tarball paths
have publication-only README sanitization and normalized archive-owner metadata;
code, package metadata and license member bytes are unchanged. Relevant npm lock
integrities identify the new archives. Component versions have not changed.

Full-history and initial-snapshot strategies are evaluated separately in the
maintainer review. A history-preserving candidate retains topology, messages and
instants with anonymized identities; an initial snapshot intentionally starts a
new publication history. Neither contains original private commit objects. The
selected release's reviewed source IDs identify its actual publication history.
The previously approved RC2 ZIP is unchanged and is not rebuilt by this process.
