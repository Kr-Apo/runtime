# Publication source provenance

This is a community-developed derivative maintained independently by Kr-Apo.
The original projects are [Ankhimate/editor](https://github.com/Ankhimate/editor)
and [Ankhimate/runtime](https://github.com/Ankhimate/runtime).
This derivative is not officially endorsed or maintained by the upstream
Ankhimate organization. Original MIT OR Apache-2.0 licensing, copyrights and
third-party attribution requirements are preserved. Naming identifies upstream
origin; no upstream trademark license or endorsement is claimed.

The publication branch retains the original public upstream ancestry and author
attributions unchanged. One new publication commit applies the approved sanitized
snapshot's file contents; the snapshot commit history and private development
commits are not imported. New publication-preparation commits use the maintainer-approved
collective identity Ankhimate Contributors with an empty email field. It denotes
anonymization and does not reattribute any original upstream commit.

Documentation home paths and fixture-source labels are portable. Existing native
data/pixel oracles are unchanged. Three stored core npm tarballs have README-only
sanitization and normalized archive owner metadata; package code and license
members are unchanged, and affected lockfile integrity fields match those bytes.
Component versions are unchanged. The accepted RC2 ZIP is neither rebuilt nor
repacked. Source preparation and the historical RC2 binary qualification are
separate evidence sets. See the release's source provenance notice for exact pins.
