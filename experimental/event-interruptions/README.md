Requires explicit crossfade + animatedSlots + animationEvents + interruptible.
See [the A15 contract](../events-crossfade/README.md). New starts have empty event
windows; frozen pose/slot sources never continue abandoned event timelines.
The one accepted B6 queue remains available regardless of graphics success.
Controls display occurrences only and warn about epoch/pending replacement.
