# Gate B wrappers

Explicit `{crossfade:true,animatedSlots:true,interruptible:true}` only.
See [the A14 contract](../slot-crossfade/README.md).
Use the shared builder with its last argument `b`. Gate A wrappers do not admit
interruptions. Hit/Death capture the accepted numerical pair; replay reconstructs
and verifies it. These controls never use the last displayed frame as a source.
