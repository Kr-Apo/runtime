# Experimental bounded ReplayV1 admission (N4)

This **Node-only, opt-in** entry is separate from the npm core and all adapters. It owns its consumer privately; no consumer, transport, mutable context, solver callback or dependency injection is returned. Existing unguarded APIs remain unchanged. It does not authorize graphics, meshes, browser engines, host time or infinite playback.

## Trusted local bank

`loadApprovedBank({ manifestPath, approvedManifestSHA256, buildPath })` requires an independently pinned SHA256 from a trusted local operator. The manifest uses `ankhimate.local-bounded-bank/1` and entries with `id`, `bundle`, `certificateSHA256`, full independent `expected` N3 request, `requestHash`, exact native `asset` and author `project` paths. N4's lab pins exactly the ten favorable, maintainer-accepted N3 trajectories. There is no default manifest or automatic approval of an imported bundle.

The bank verifies actual N3 evidence through its unchanged verifier, numeric build/engine identity, project/assets, native bytes and exact request. Every new authorization rechecks evidence seals even when the expensive numerical proof comparison has already been cached. Prepared references are private immutable snapshots; a running session does not reread external files. Starting an already issued ticket rechecks the numeric build and executes the captured authorized data, not a caller-owned rig.

Unsigned proof integrity is distinct from trusted issuance. The operator must protect the pinned manifest/digest outside untrusted bundle input. This is not authentication against a malicious local user changing both their code and trust anchor. No signature service or generic character certificate system is added.

## Surface

```js
const bank = loadApprovedBank(trustedConfig);
const ticket = await bank.authorize({
  qualificationId, history: 'bulk', instanceId: 'scene-1',
  nativeBytes, request: independentlyApprovedRequest,
});
const session = bank.start(ticket, 'scene-1'); // ticket consumed once, bank/instance bound
while (!session.observe().complete) session.execute(session.next());
session.present(snapshot => { /* read-only presentation; synchronous, detached */ });
session.dispose();
```

Only `observe`, `preview`, `next`, `execute`, `present`, `dispose` are public. Outputs are recursively frozen detached copies. Each command envelope carries the session UUID; foreign/stale commands, extra fields, altered budgets or epochs and unqualified sequences are refused before dispatch. Disposal is terminal resource cleanup, not reset or recovery.

Only the exact N3 `step`, `bulk`, `replay` or `reset` transcript chosen for that session is allowed. H is inclusive **when that command belongs to the transcript**; H+1 is refused before any consumer call, intent update or tick. Rational time and host-time commands are not enabled, including those within H. Pending backlog cannot grant extra pumps after the transcript or extend the qualified target. No silent clamping.

Every candidate is checked before B6 commit for finite bones/records and exact membership in the pinned TS trajectory from the same engine. This compares existing values, not new equations or new Rust/TS thresholds. Initialization, reset, preview and transport endpoints are also checked. Geometric vertices are not generated by this API; existing N3 geometry evidence is verified, but no new rendering capability follows.

`AdmissionError.kind` distinguishes TRUST, CERTIFICATE, ADMISSION, HORIZON, SIMULATION, PRESENTATION and STATE. A simulation/audit fault closes the session to further mutation; observe remains available and dispose is allowed. No implicit resume or reset after fault is qualified. A fresh authorization creates a distinct instance from origin. Presentation failure does not fault or advance simulation. Async presentation is refused.

## Tests

Run with **plain Node**, because N3 pins engine flags (do not add `--test`):

```powershell
node experimental/bounded-replay/admission.test.mjs <trusted-lab-config.json>
node experimental/bounded-replay/sealing.test.mjs <trusted-lab-config.json>
node experimental/bounded-replay/fault.test.mjs <trusted-lab-config.json>
```

Use a NEW scratch directory in the lab config. `fault.test.mjs` creates explicitly labelled controller-source copies with injected precommit observer faults. It does not expose an injection API or change C7A modules, N3 proofs or Physics equations. These are deterministic transactional fault tests, not natural failures of the favorable trajectories.

PixiJS and Phaser still expose their old raw consumers. They are **not guarded by N4**. A future integration must use a separately qualified numeric engine/authority and the owned surface only; it must not also expose another route to the same consumer. Browser/WebGL2 qualification and weighted rendering remain HOLD/NOT_RUN.
