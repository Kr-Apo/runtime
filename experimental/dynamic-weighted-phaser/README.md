# G2: dynamic weighted Phaser presentation

Local experimental entry, not an npm export. Scope: the four exact Q1 requests
Courier regions/combined × primary/delayed, H256 inclusive, step/bulk/replay/reset.
No new Physics, calendar, evaluator, formats, dependencies or public API.

## Reuse and authority

`bench.mjs` uses the unchanged Q1 supervisor and independent anchor. It authorizes
and starts a private numeric session before binding a view. `host.mjs` creates a
separate Chrome/Phaser3.90/WebGL2 process. Only accepted detached frames and native
selection are transmitted; no Consumer/provider/context getter or numeric command
channel exists in the renderer. Actual V8 coverage verifies zero numeric owner,
Physics, transport, canonical sampling and evaluate execution. Transitive core
definitions may load through MeshAtlas; definition presence is not execution.

The bridge reuses C7C1 opaque WeakMap tokens: instance/session/cursor/epoch and full
snapshot, distinct simulated/preview kinds. An old/foreign/copied token refuses.
Preview uses the existing seek60 and its own skin. Renderer cursors are monotone;
same-cursor retries preserve the same accepted frame. No graphical setSkin, free
seek or host-time route is added. The numeric calendar does not restart at clip
loop240. H257 and foreign commands are refused by Q1 before simulation.

## Phaser geometry and transaction

G1 dynamic validation, native Q1 resolution, R2 weightedPoints, MeshAtlas and
regionQuad are reused unchanged. No numerical membership is recomputed. Resolve
selected owner/slot/name, then default fallback or explicit absence. Static Normal
blend only; existing Phaser DarkTint is used at D=0. FFD/links/clipping/mixing and
other constraints are excluded.

Skinning sums native weights and binding points in native order with accepted
world matrices, normalizes positive totals, and uses the native host for empty/
zero rows. No influence pruning, four-bone cap, inverse-bind reconstruction or
early numeric downcast. Logical draw arrays cross the same Float32 boundary as
G1. Phaser Mesh expects Y-up before public Face projection: v.y=-drawY,
setOrtho, Face.transformCoordinatesLocal. This is the C7C1 convention, not a
camera inversion. Vertex.setUVs updates u/v AND tu/tv.

Each back/front bank caches by owner/slot/attachment. Region/mesh4/mesh5 therefore
own separate Mesh/Face/Vertex arrays, indices, UVs and texture identities. Hidden
entries remain bounded by the actual native identities: maximum118 meshes,
240 Faces,720 Vertex per Combined view. No mutable vertices are shared between
views. Atlas pages are borrowed and checked against TextureManager, Texture,
TextureSource identity, dimensions and live PMA wrappers on every presentation.

Validate, prepare all geometry, draw back DynamicTexture, check GL/context, then
publish front. Ordinary errors retain the previous front and never advance Q1;
the same accepted snapshot can retry. This is not universal GPU atomicity.
DynamicTexture capture and intermediate blit are retained and timed explicitly.
Context loss destroys usable pixels; restore and redraw do not modify Physics.

Scene shutdown/destroy releases its view resources, not other borrowers' atlas
pages. Game owns shared pipelines, batch buffers and capture targets. Closing
the host closes its context; no physical VRAM-free claim is derived from logical
Mesh IDs or diagnostic GL registries. Scene/Game lifecycle tests are explicit.

## Real GPU evidence

Phaser expands triangles into a shared SinglePipeline batch, not per-mesh GL
buffers. bufferData/bufferSubData shadows are compared byte-for-byte with actual
getBufferSubData reads at drawArrays. Each draw records native owner/key, logical
mesh/instance identity, real GL buffer/texture/framebuffer, attribute offsets,
stride, expanded positions and UVs. Logical Vertex IDs remain explicitly labeled.

The G2 comparator reuses G1's independent Float32 UV coverage metric with all
historical thresholds unchanged, then checks actual expanded GPU attributes
against public projected vertices and the independent Rust/Decimal geometry.
Pixels are compared to accepted G1 and independently rasterized source-PNG CPU
references at exactly the same280 snapshots/placements. No data, image alignment,
golden or tolerance is changed. Capture points remain those in the G1 plan.

## Local reproduction

Use the archived configs/drivers and fresh output directories:

```text
node --test experimental/dynamic-weighted-phaser/adapter.test.mjs
node experimental/dynamic-weighted-phaser/measure.test.mjs <config.json>
node experimental/dynamic-weighted-phaser/qualify.mjs <config.json>
node experimental/dynamic-weighted-phaser/safety.mjs <config.json>
node experimental/dynamic-weighted-phaser/special.mjs <config.json>
node experimental/dynamic-weighted-phaser/safety-extra.mjs <config.json>
node experimental/dynamic-weighted-phaser/profile.mjs <config.json>
```

Measure/corruption tests consume actual saved readbacks; synthetic readback/native
mutations are labeled separately from real GL submissions and fault injections.
Fault adapters/controllers are independently hashed copies, never favorable
qualifications. Raw lower-level graphics RPCs belong to the trusted local test
launcher, not an admission API for hostile pages.

Profiles use the G1 protocol, one/two views, step0..256 plus40 steady samples and
20 separate allocation samples. No outliers removed. Selection validation,
attachment resolution, mesh lookup/creation, UV updates, Face projection and
uploads are nested costs, not additive independent totals. Timer resolution can
yield zero for short phases; it does not mean zero cost. GPU queries include the
DynamicTexture capture/blit and final composition, not only skinning. No FPS,
headful, other-GPU, unbounded replay or general runtime qualification is implied.
