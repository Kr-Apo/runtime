# G1: experimental dynamic weighted PixiJS presentation

This local entry accepts only the four independently pinned Q1 requests,
Courier regions/combined × primary/delayed, H256 inclusive and their four exact
histories. It is not a public npm API or an unbounded Physics guarantee.

`bench.mjs` reuses the unchanged Q1 supervisor/bank/anchor. Numeric execution is
private in a separate Chrome process. `host.mjs` launches a graphics-only Chrome
process; `adapter.mjs` consumes detached accepted frames and selections, never
constructs a consumer, samples animation or calculates Physics membership.

The normal bridge reads the actual accepted snapshot. Preview uses the original
qualified seek60 only. No extra seek, free host-time or runtime setSkin exists.
The renderer checks session/history/clip, H, health, actual completed tick, the
approved selection, record IDs and native attachment resolution. The native
selected-skin/default fallback is independent of numerical membership. Absence is
explicit. Same-cursor retries are allowed only for the same accepted frame;
presentation mode/placement may differ. Older cursor snapshots are refused.

## Geometry, ownership and publication

R2 `weightedPoints`, native `regionQuad`, `MeshAtlas` and the accepted DarkTint
shader are reused unchanged. There is no pruning, four-influence cap or inverse
bind reconstruction. The dynamic validator is separate; fixed R2 default-only
guards remain unchanged. Actual exported binding coordinates and weights are
used in native order; conversion to Float32 happens at the buffer boundary.

Two back/front banks cache meshes by native owner/slot/attachment. Different
topologies/pages never reuse the wrong UV/index buffers. Cache cardinality is
bounded by twice the native attachment identities. Visible meshes follow native
draw order; absent entries are hidden. Borrowed atlas pages are not owned by a
view, and their source identity/dimensions/liveness are checked.

Preparation validates data and finite buffers, renders the back target, checks
GL errors/context loss, then publishes the front. Ordinary preparation/submission
failure preserves the prior front and numeric state; rendering can retry the
same accepted snapshot. This is not universal GPU atomicity. A lost context has
no usable image until restoration; numeric state and last accepted presentation
metadata remain separate. Destroying a view releases its meshes, effects,
geometries and targets, not borrowed assets. Host disposal closes the context.

The independent control renderer reuses a private stage to avoid retaining two
Pixi batch buffers per temporary control capture. It does not share actual view
geometry or compute Physics. Control resources and actual view resources are
measured separately. No fixed historical renderer was edited for this fix.

## Qualification

Use the archived G1 configs/drivers from the local delivery. Fresh output
directories are required by campaign entry points.

```text
node experimental/dynamic-weighted-pixi/geometry.test.mjs <config.json>
node experimental/dynamic-weighted-pixi/measure.test.mjs <config.json>
node experimental/dynamic-weighted-pixi/qualify.mjs <qualification-config.json>
node experimental/dynamic-weighted-pixi/safety.mjs <safety-config.json>
node experimental/dynamic-weighted-pixi/safety-extra.mjs <safety-extra-config.json>
node experimental/dynamic-weighted-pixi/profile.mjs <profile-config.json>
```

The source acceptance test uses the exact combined native from config.exports.
The measure regression uses preserved pilot-v2 readbacks: it proves the old
normalized-area false discrepancy caused by comparing Float32 GPU UV coverage
with double coverage on tiny regions. G1 independently rounds reference UVs at
that same boundary; every historical numerical/pixel threshold remains unchanged.
The fixed R2 comparator is preserved, and corruption tests still fail.

Oracles are independent Decimal70 calculations from exact Q1 Rust bones/binds.
GPU vertex/UV/index buffers are read with getBufferSubData and matched to actual
drawElements bindings. Pixels are checked both against independently generated
Rust/Decimal control geometry and a CPU triangle rasterizer using exact author
PNGs. Historical uniform/edge thresholds are unchanged. No image registration,
asset correction or golden update is used.

Precise V8 coverage records that Consumer/Physics/transport/evaluate are never
executed in the graphics context. Their modules are loaded through the unchanged
MeshAtlas barrel dependency; module presence is not a second numeric instance.
The graphics context has no numeric session/facade/provider or command channel.

Fault adapters/controllers are explicit separately hashed copies, never positive
qualifications. Reports distinguish real GL faults, synthetic mutations of saved
readbacks, and in-memory invalid native copies. Timing keeps cold/steady/transition
outliers; allocation sampling is separate. Only one and two views are qualified.

No FFD, linked meshes, clipping, mixing, Phaser dynamic skins or production API
integration is implemented here. Editor E1, native formats, Physics equations,
Q1 certificates, fixed banks and RC2 remain unchanged.
